# Indian Agricultural Production Analysis – Excel Dashboard

## 📌 Project Overview

This project analyzes Indian agricultural foodgrain and rice production data from 2005 to 2014 using Microsoft Excel and Power Query.

The analysis focuses on identifying production trends, year-over-year (YoY) growth, and differences between Kharif and Rabi rice production.

## 🎯 Objective

The main objectives of this project were to:

- Clean and transform agricultural production data.
- Analyze foodgrain and rice production trends from 2005–2014.
- Calculate year-over-year production growth.
- Compare Kharif and Rabi rice production.
- Identify important production trends and changes.
- Build an Excel dashboard to communicate the findings visually.

## 🛠️ Tools & Technologies

- Microsoft Excel

## 📂 Dataset

The dataset contains agricultural production information covering the period from 2005 to 2014.

The analysis focuses on:

- Foodgrains
- Rice
- Rice Kharif
- Rice Rabi

## 🔄 Analysis Process

The project followed the following workflow:

**Raw Data → Power Query → Clean Data → PivotTables → YoY Analysis → PivotCharts → Dashboard → Insights**

### Data Cleaning

Power Query was used to prepare and organize the raw agricultural production data for analysis.

### Data Analysis

Excel formulas were used to calculate year-over-year growth.

The following production categories were analyzed:

- Foodgrains
- Rice
- Rice Kharif
- Rice Rabi

### Data Visualization

PivotTables and PivotCharts were used to visualize production trends and compare Kharif and Rabi rice production.

## 📊 Dashboard

The Excel dashboard contains:

- Foodgrain production trend
- YoY production growth
- Kharif vs Rabi production comparison
- KPI cards for overall growth
- Key analytical insights

## 🔍 Key Insights

- Overall foodgrain production increased by **33.28%** between 2005 and 2014.
- Rice production increased by **27.86%** during the same period.
- Kharif rice production remained substantially higher than Rabi rice production throughout the period.
- The Kharif–Rabi production gap reached its highest level of approximately **80.26 million tonnes in 2012**.
- Rabi rice showed notable year-to-year volatility, ranging from **+24.03% in 2006 to −18.32% in 2012**.

## 💡 Conclusion

The analysis shows an overall increase in agricultural foodgrain and rice production between 2005 and 2014. Kharif rice consistently contributed a larger share of production than Rabi rice, while the production gap between the two varied considerably across the period.

The project demonstrates the use of Excel and Power Query for data cleaning, analysis, visualization, and dashboard development.
